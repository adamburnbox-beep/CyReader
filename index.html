Add a feed

Feeds are defined in feeds.json. Fill this in, copy the snippet, add it to the list on GitHub and commit — the builder re-runs automatically and the feed appears within a minute or two.


  

    Open feeds.json on GitHub ↗

  
Optional per-feed keys: enabled (false to pause), max_items, include / exclude keyword lists, default_severity. Severity, CVSS and CVE IDs are auto-detected from titles and summaries; CVEs are also checked against CISA KEV and EPSS.
